Mayhem Asset Tools

A custom production-tool workflow made to speed up the preparation of vehicles and game-ready data for Mayhem Drive.

◆

WHY I BUILT IT

Vehicle assets need consistent names, damage states, detach points and export structure. Repeating those steps manually makes mistakes much more likely, so I began turning the workflow into reusable Blender tools.

TOOLING FOCUS

  • Preparing and organizing vehicle meshes for export.
  • Handling structured damage-state naming.
  • Creating detachable-part and spawn-point data.
  • Keeping Blender-to-Unity exports predictable.
  • Reducing repetitive setup through Python automation.

WHAT I LEARN FROM IT

This project is as much about pipeline design as scripting. A good tool is not simply one that automates a task; it needs to fit the way assets are actually authored, make mistakes visible and produce consistent results for the game engine.
